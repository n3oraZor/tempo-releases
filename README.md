# Tempo

Client mail pour Mac (macOS 15 ou plus récent), signé et notarisé par Apple.

**[Télécharger Tempo 1.2.1](https://github.com/n3oraZor/tempo-releases/releases/latest/download/Tempo.dmg)** — ouvrir le fichier, glisser Tempo dans Applications.

Ensuite, Tempo se met à jour tout seul : il vous prévient quand une nouvelle version est prête.

Ce dépôt ne contient que les versions publiées et le fichier de mises à jour (`appcast.xml`).
