# Clark Mail

Client mail pour Mac (macOS 15 ou plus récent), signé et notarisé par Apple.

**[Télécharger Clark Mail 1.7.5](https://github.com/n3oraZor/tempo-releases/releases/latest/download/ClarkMail.dmg)** — ouvrir le fichier, glisser Clark Mail dans Applications.

Ensuite, Clark Mail se met à jour tout seul : il vous prévient quand une nouvelle version est prête.

Ce dépôt ne contient que les versions publiées et le fichier de mises à jour (`appcast.xml`).
